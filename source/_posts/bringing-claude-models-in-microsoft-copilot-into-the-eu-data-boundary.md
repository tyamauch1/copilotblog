本日、Microsoft Copilot で利用できる Anthropic の Claude モデルが EU Data Boundary の対象になることを発表します。これにより、ヨーロッパ各地の組織にとって、モデルの選択肢がさらに充実します。お客様は、Claude モデルへのアクセスと、これまで頼りにしてきた Microsoft の地域内でのデータ処理に関する確約のどちらかを選ぶ必要がなくなります。2026 年末までに、欧州連合 (EU) および欧州自由貿易連合 (EFTA) の組織は、Copilot Cowork (Cowork) を含む Copilot の各種機能で Claude モデルを利用する際に、データがすでに保存されている EU Data Boundary 内で処理を行えるようになります。

## これまでの EU Data Boundary に関する確約をさらに拡充

[EU Data Boundary](https://learn.microsoft.com/privacy/eudb/eu-data-boundary-learn) は、Microsoft 365 やその他のオンライン サービスのデータを EU および EFTA 内で保存・処理するという、Microsoft 独自の業界をリードする確約です。現在の規制要件を上回るもので、Microsoft の包括的なコンプライアンス関連のサービスと認証に基づいています。

EU および EFTA の対象となる Microsoft 365 のお客様には、契約条件に含まれており、オプトインや追加購入は必要ありません。EU Data Boundary に関する確約には、透明性、説明責任、データ保護という Microsoft の原則が反映されています。よりきめ細かな制御が必要な組織は、EU および EFTA の 10 か国で利用できる[国内でのデータ保存](https://learn.microsoft.com/microsoft-365/enterprise/m365-dr-compare-offerings)を使って、Microsoft 365 の保存データを自国内に置くこともできます。

Claude モデルは、Microsoft が運用するモデルを含め、すでに EU Data Boundary 内でデータを処理している主要なモデルに加わります。これにより、規制対象の業界や公共部門を含む組織は、最新の AI ソリューションを組織全体に広げる際に、コンプライアンス要件への対応を進めやすくなります。

## 一貫した確約の下でモデルを選択

Copilot は、Anthropic やその他のプロバイダーの主要なモデルを、業務の情報に基づく、ガバナンスの効いた 1 つの利用環境に統合します。従業員は、目の前のタスクに合ったモデルを選べます。Claude モデルは、Chat、Microsoft 365 アプリ内の Copilot、Cowork、Copilot Code など、Copilot の各種機能ですでに業務を支援しています。

Copilot の Claude モデルには、[Microsoft のエンタープライズ データ保護](https://learn.microsoft.com/microsoft-365/copilot/enterprise-data-protection)が適用されます。お客様のデータが生成 AI の基盤モデルのトレーニングに使われることはなく、誰がモデルを利用できるかは管理者が決定します。そのため、組織は一貫したセキュリティ、コンプライアンス、ガバナンスの下で、複数のモデルを選べる利点を活用できます。

## 今後の予定

すでに Copilot で Claude モデルを利用している組織では、対応は必要ありません。提供が開始されると、これらのモデルの処理は自動的に EU Data Boundary 内に移行します。

まだ Claude モデルを有効にしていない組織は、いつでも有効にできます。この場合も、提供開始後に処理が EU Data Boundary 内に移行します。EU および EFTA では、この設定は既定で無効になっています。管理者は Microsoft 365 管理センターで、すべての利用者、または選択した利用者やグループに対して有効にできます。詳細は、Microsoft Learn の「[Microsoft Online Services の Claude モデル](https://learn.microsoft.com/microsoft-365/copilot/connect-to-ai-subprocessor)」を参照してください。提供開始が近づいた段階で、さらに詳しい情報をお知らせします。

AI は急速に進化しており、タスクに最適なモデルも変わる可能性があります。Copilot は、使い慣れたセキュリティ、コンプライアンス、管理のための制御を備え、進化する主要なモデルを導入するための、ガバナンスの効いた 1 つの利用環境を組織に提供します。EU Data Boundary を Claude モデルに拡大することは、その次の一歩です。ヨーロッパ各地の組織は、信頼しているデータに関する確約の下で、Copilot の最新の AI を利用できるようになります。

詳しくは、[EU Data Boundary](https://learn.microsoft.com/privacy/eudb/eu-data-boundary-learn) と [Microsoft Copilot の AI モデル](https://learn.microsoft.com/microsoft-365/copilot/ai-models-overview)を参照してください。
